# Samsung BU8000 の Tizen OS を整理する：プリインストールアプリ、視聴データの収集、おすすめ表示

Samsung Smart TV の不要なプリインストールアプリと自動コンテンツ認識（ACR）を停止する方法、および Smart Hub のおすすめ欄を非表示にする方法を紹介します。**UE55BU8000UCCE**、ファームウェア **T-KSU2EBDEUC-1720.7**（Tizen 6.5）で個別に検証しました。おすすめ欄だけを消したい場合は、最初の手順を参照してください。

## 標準のアプリ画面から「専門家のおすすめ」を消す

1. 「このテレビについて」で型番とファームウェアを確認します。元の `AppsCommon.dll` と `AppsCommon.ni.dll` をバックアップし、それぞれの SHA-256 を表と照合します。変更にはテレビの管理者権限が必要です。[ハッシュ値と手順（ロシア語）](docs/smart-hub.md)
2. 両方の値が一致した場合に限り、インストール済みアプリの表示に切り替えるパッチを適用します。対象は「ホーム → アプリ」です。適用時にホーム画面が再起動するので、視聴が終わってから作業してください。
3. アプリ画面を開き直し、インストール済みのアプリを起動して、スマートホームからテレビを操作します。実機ではおすすめ欄が消え、どちらの操作も成功しました。元に戻すには、バックアップした**両方のファイル**を復元します。

## Samsung のプリインストールアプリを無効にする

1. 対象の37項目を確認してください。プロファイルをすべて適用すると、音声機能、TV Plus、Gaming Hub、リモートサポートも停止します。これらを使っている場合は、プロファイルの一括適用を見送ってください。[無効化するアプリと保護するアプリ](profiles/bu8000-1720.7.json)
2. PC で `python tools/generate_cleanup.py` を実行します。適用・確認・復元用のスクリプトが `build/cleanup/` に生成されます。適用にはテレビの管理者権限が必要です。初回適用時に作成される `baseline.tsv` には各アプリの元の状態が記録されるため、保管してください。 [適用と復元の手順（ロシア語）](docs/cleanup.md)
3. `verify.sh` を実行し、インストール済みのアプリとスマートホームからの操作を確認します。元に戻す場合は、保存した初期状態を使って `restore.sh` を実行し、テレビを再起動します。

電源プラグを抜いてから起動した際の記録では、起動85秒後、コンテンツ認識を含む対象の7サービスがすべて `inactive`、`MainPID=0` でした。検証時の設定は `Host PC IP = 127.0.0.1` です。公開版ツールの動作確認は PC 上で行いました。[実機の起動記録](evidence/cold-boot-sanitized.json) · [公開版の検証内容（ロシア語）](docs/validation.md)
