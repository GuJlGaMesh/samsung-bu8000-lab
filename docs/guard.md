# TV Privacy Guard

Runtime-маски systemd исчезают после перезапуска. Helper повторно получает локальные привилегии, восстанавливает семь масок, проверяет результат, закрывает root-соединение и завершается. Это не постоянный процесс «чистки RAM».

## Host PC IP

| Значение в Developer Mode | Проверенный результат |
|---|---|
| Адрес компьютера | Установка и диагностика с ПК; полная автономная очистка после cold boot не подтверждена |
| `127.0.0.1` | Локальный helper успешно отработал после cold boot; доступ с ПК после перезапуска не работал |

В конце опыта пользователь выбрал адрес ПК. Нельзя утверждать, что в окончательной конфигурации семь служб гарантированно блокируются при каждом старте.

## Сборка

Сначала выполните [подготовку](setup.md) и [apply](cleanup.md). Публичный helper требует baseline публичного набора и четыре marker-файла. Личный старый backup имеет другую структуру и автоматически не переносится.

```powershell
python tools/build_guard.py
apps2samsung-cli install dist/tv-privacy-guard-unsigned.wgt --tv $tvIp --local-ip $pcIp --partner --json
```

Для автономного теста вручную задайте Host PC IP = `127.0.0.1` и сделайте холодный перезапуск. В историческом опыте отчёт получен примерно на 85-й секунде загрузки.

Результат: `/home/owner/share/tvprivacyguard-status.json`. `ok=true` означает проверенные состояния в этот момент. Окно приложения или «команда запуска отправлена» не доказывает успех. Чтение с ПК может потребовать смены режима доступа и ещё одной загрузки; учитывайте время отчёта и не запускайте helper вручную до сохранения старого результата.

## Публичная версия

- Отчёт остаётся на ТВ; HTTP callback, адрес домашнего ПК и секрет отчётности исключены.
- Проверяются все 37 app ID вместо 33 в позднем историческом helper.
- Требуется baseline публичного apply-скрипта.
- Сохранены правки адаптера: нет уборки staging других инструментов, отдельный журнал, уборка собственного staging.

Исходная логика проверена на ТВ, **эта сборка с изменениями проверена только локально**. Повторный cold-boot тест ещё нужен. Нет замены Home, установки launcher Vetro или автоматической смены Host PC IP.

Для отката сначала отключается `tvprivgrd1.svc`, затем выполняется `restore.sh`. Удаление одного WGT не восстанавливает app-флаги и marker-файлы.
