# نتائج التحقق

[README](../../README.ar.md) · [إعداد التلفزيون والحاسوب](setup.md) · [إخفاء التوصيات من تبويب التطبيقات](smart-hub.md) · [تعطيل المكوّنات واستعادة حالتها الأصلية](cleanup.md) · [قراءة تقرير بدء تشغيل Privacy Guard](guard.md) · **نتائج التحقق**

في 10 نوفمبر 2026 نجحت ثلاثة اختبارات Python على الحاسوب. رُفضت الملفات الثنائية المجهولة عند التعديل والاستعادة، والتطبيقات المحمية في قائمة التعطيل، ومحارف الصدفة الخاصة في المعرّفات. أعادت العملية العكسية ملف DLL الأصلي مطابقًا بايتًا ببايت.

طابق تعديل النقل في Windows نسخة المصدر المحددة. تم بناء مكوّنَي .NET بنجاح واجتازت الحزمة غير الموقّعة فحصَي ZIP وXML. يعود تنبيه انتهاء دعم .NET Core 3.1 إلى الإصدار المستخدم على التلفزيون.

يشغّل التكامل المستمر اختبارات Python وينشئ السكربتات ويفحص صياغة shell وJavaScript والملفات المنشورة. تم التحقق من الروابط المحلية ومراجعة المحتوى بحثًا عن بيانات خاصة. سجل التلفزيون أدناه من اختبار التشغيل السابق بعد فصل الكهرباء. تم فحص الأدوات المنشورة على الحاسوب.
