# 读取 Privacy Guard 开机报告

[README](../../README.zh-CN.md) · [准备电视和电脑](setup.md) · [隐藏“应用”页签中的推荐](smart-hub.md) · [停用组件并恢复原始状态](cleanup.md) · **读取 Privacy Guard 开机报告** · [验证结果](validation.md)

临时屏蔽会在重启后失效。助手重新设置七项屏蔽、检查服务、写入本地报告后退出。它依赖公开配置生成的初始状态文件和四个停止标记。旧备份的格式不同。

测试将地址设为 `Host PC IP = 127.0.0.1`，冷启动约 85 秒后收到报告。改用电脑地址可以从电脑诊断。用户最终保留了电脑地址，该设置下冷启动后的自动清理效果尚待验证。

查看 `/home/owner/share/tvprivacyguard-status.json` 的时间戳。`ok=true` 表示记录当时的状态。手动启动助手前请保存已有报告。为从电脑读取报告而更改主机地址可能需要再次重启。公开版将报告保留在电视上，检查 37 个应用并清理自己的临时文件，已在电脑上检查。还原时，`restore.sh` 会停用 `tvprivgrd1.svc` 并恢复标志和标记。
