2026 年 11 月 10 日、PC で Python テストが 3 件成功しました。適用・逆変換の両方で未知のバイナリを拒否し、無効化対象に含まれる保護アプリや、ID に含まれるシェルのメタ文字も拒否しました。アプリ用パッチを適用して逆変換した DLL は元のファイルとバイト単位で一致しました。

Windows 用の転送パッチは固定したソースのリビジョンと一致しました。2 個の .NET コンポーネントをビルドでき、未署名パッケージは ZIP と XML の検査を通過しました。.NET Core 3.1 のサポート終了警告はテレビの実行環境に対応しています。

CI は Python テスト、スクリプト生成、シェルと JavaScript の構文検査、公開ファイルの検査を行います。ローカルリンクを確認し、公開対象に個人情報が含まれないかを点検しました。実機の記録は以前のコールドブート試験のものです。公開版ツールは PC 上で確認しました。
