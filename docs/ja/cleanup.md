# コンポーネントの無効化と復元

[README](../../README.ja.md) · [テレビと PC の準備](setup.md) · [アプリ画面のおすすめを非表示にする](smart-hub.md) · **コンポーネントの無効化と復元** · [Privacy Guard の起動レポートを読む](guard.md) · [検証結果](validation.md)

対象は 37 個のアプリ ID です。内訳はコンテンツ認識・分析・ターゲティング広告が 4 個、オプション機能が 28 個、追加の広告関連が 5 個です。7 サービスを停止して一時的にマスクし、4 個の停止マーカーのうち新規作成したものを記録します。スマートホームとアカウントを含む 24 個の保護対象 ID を確認します。音声機能、TV Plus、Gaming Hub、リモートサポートを使う場合は一括適用を見送ってください。

[bu8000-1720.7.json](../../profiles/bu8000-1720.7.json)

PC でスクリプトを生成し、`build/cleanup/` の内容を確認します。無効化後もパッケージとデータは保持されます。データベースは読み取り専用です。

```powershell
python tools/generate_cleanup.py
```

型番とファームウェアを目視で照合し、`apply.sh` を `private/apply.sh` にコピーして `set -eu` の次に `export BU8000_LAB_CONFIRMED=1` を追加します。テレビで管理者権限を使ってコピーを実行し、続いて `verify.sh` を実行します。成功すると `APP_CONFIG_OK` が表示されます。無効 37、保護 24、全 7 サービスが次の状態であることを確認します。

```text
LoadState=masked
ActiveState=inactive
MainPID=0
```

`/opt/usr/home/owner/share/bu8000-lab-backup/baseline.tsv` を PC にも保管します。再実行しても最初の状態は保持されます。中断時には一部の変更が反映済みの場合があります。既存のマスクや上書き設定が初回適用を妨げる場合、その設定は保持してください。保存した状態は元のプロファイルとファームウェアに限って使います。

同じテレビで `restore.sh` を実行すると起動サービスを無効にし、アプリのフラグを元に戻し、自分で作成したマーカーのみを削除して一時マスクを解除します。コールドブート後、ホーム画面とスマートホームを確認します。Host PC IP がループバックなら、PC のアドレスに戻して再起動してからリモート接続します。旧版では 33 個と残り 4 個を別々に確認し、公開版は 37 個すべてを確認します。
