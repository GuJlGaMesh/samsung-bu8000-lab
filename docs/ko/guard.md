# Privacy Guard 부팅 보고서 읽기

[README](../../README.ko.md) · [TV와 PC 준비하기](setup.md) · [앱 탭에서 추천 숨기기](smart-hub.md) · [구성 요소 비활성화 및 원래 상태 복원](cleanup.md) · **Privacy Guard 부팅 보고서 읽기** · [검증 결과](validation.md)

임시 마스크는 재부팅하면 사라집니다. 도우미는 마스크 7개를 다시 적용하고 서비스를 확인한 후 로컬 보고서를 쓰고 종료합니다. 공개 프로필의 최초 상태 파일과 정지 표식 4개가 필요합니다. 기존 백업은 형식이 다릅니다.

`Host PC IP = 127.0.0.1` 로 설정한 콜드 부팅에서는 약 85초 후 보고서를 받았습니다. PC 주소를 사용하면 컴퓨터에서 진단할 수 있었습니다. 최종적으로 선택한 PC 주소 설정에서 콜드 부팅 후 자동 정리 여부는 확인되지 않았습니다.

`/home/owner/share/tvprivacyguard-status.json` 의 작성 시각을 확인하세요. `ok=true` 는 그 시점의 상태입니다. 수동으로 도우미를 실행하기 전에 보고서를 저장하세요. PC에서 읽기 위해 주소를 바꾸면 다시 부팅해야 할 수 있습니다. 공개 버전은 보고서를 TV에 보관하고 앱 37개를 검사하며 자체 임시 파일을 정리합니다. PC에서 검증했습니다. 복원 시 `restore.sh`가 `tvprivgrd1.svc` 를 비활성화하고 플래그와 표식을 복원합니다.
