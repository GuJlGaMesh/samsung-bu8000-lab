# Медиа-приложения: результаты, а не список рекомендаций

Установленный пакет и открывшийся каталог ещё не означают, что нужный сериал воспроизводится с нужной озвучкой. Эти результаты относятся к конкретному сеансу исследования; доступность удалённых каталогов могла измениться.

| Приложение | Что проверили | Итог |
|---|---|---|
| Zona, отдельный ярлык MSX | Каталог, пульт, видео и звук; пользователь не заметил лагов | Позже отвергнута из-за малого выбора озвучек |
| Lampa, пакет Sunic 2.3.71 | Установка и каталог | Реклама при запуске; отключение необязательного фонового helper не сделало приложение без рекламы |
| StremioK 2.2.2 | Установка и интерфейс | Настройка источников и воспроизведение не завершены |
| Nuvio Legacy 2.0.8 | Установка и запуск процесса | Визуальная работоспособность и видео не подтверждены |
| MSXPlayer v4 | Отдельный магазин/launcher открылся | Пользователь также видел пустой экран MSX с предложением добавить launcher; готовый сценарий просмотра не подтверждён |
| ForkPlayer / NUM | Исследовались варианты запуска; web-страница NUM отвечала | Успешный просмотр на этом ТВ не подтверждён |
| Seena | Исследовалась Android-версия | APK на Tizen не устанавливался |
| XSmart | Пользователь смотрел через существующую установку | Механизм подписки не установлен; изменений авторизации не делали |

Исходное меню Media Station X сохранялось. Практический вывод: устанавливать по одному кандидату и проверять конкретную серию, озвучку, перемотку и звук, прежде чем переходить к следующему.

## Независимый ярлык на базе MSX

Это отдельная оболочка с собственным package ID и хранилищем. Она не меняет настройки установленного MSX и не превращает удалённый сервис в нативное приложение.

Скачайте официальный WGT самостоятельно с [сайта Media Station X](https://msx.benzac.de/dist/tizen.wgt) в `private/msx-tizen.wgt`. Репозиторий не распространяет этот пакет. Скрипт принимает только исследованный хеш `index.html`; при обновлении upstream он остановится, пока новую версию не проверят.

Пример отдельного ярлыка Zona, воспроизводящий использованный start-параметр:

```powershell
python tools/build_msx_shortcut.py --upstream private/msx-tizen.wgt --package zonademo01 --name Zona --start 'content:https://m.zona.ms/msx/start.json>index:0>execute' --output dist/zona-unsigned.wgt
apps2samsung-cli install dist/zona-unsigned.wgt --tv $tvIp --local-ip $pcIp --partner --json
```

Переменные и сертификат: [подготовка](setup.md). Используйте свободный package ID из десяти латинских букв/цифр. Не переиспользуйте ID существующего приложения: это может заменить его. Создаваемый пример имеет app ID `zonademo01.App`; удаление этого ярлыка через Apps не должно затронуть исходный MSX. При повторной сборке выберите новый выходной файл или явно удалите предыдущий локальный WGT.

Сам MSX loader остаётся неизменным; добавляются `start.html` и новая конфигурация. Старые подписи исключаются, пакет нужно подписать своим сертификатом. Удалённые страницы и их реклама не контролируются этим репозиторием. Наличие каталога не означает предоставление прав на контент или подписку.

Первичные проекты для самостоятельного изучения: [MSX](https://msx.benzac.de/), [Lampa by Sunic](https://github.com/sunic007/lampa-samsung), [StremioK](https://github.com/Kepler75/StremioK), [Nuvio Legacy](https://github.com/iqui27/nuvio-native-legacy), [MSXPlayer](https://msxplayer.ru/). Список не является обещанием совместимости или отсутствия рекламы.
