Предупреждения .NET об окончании поддержки netcoreapp3.1 ожидаемы: это runtime исследованного ТВ. Сборка под современный desktop runtime не подтверждала бы совместимость с ним.

Не выполнялись: установка публичного WGT на ТВ, новый цикл apply/restore, cold boot с публичной сборкой, повторная проверка HDMI, SmartThings или производительности. Эти пункты нельзя считать пройденными по результату сборки или CI. Исторические результаты описаны отдельно в README и `evidence/`.

CI повторяет тесты Python, генерацию скриптов, синтаксические проверки и проверку публикуемых файлов. Он не подключается к телевизору и не выполняет полную .NET-сборку.
