# टीवी और कंप्यूटर तैयार करें

[README](../../README.hi.md) · **टीवी और कंप्यूटर तैयार करें** · [ऐप टैब से सुझाव हटाएँ](smart-hub.md) · [घटक बंद करें और मूल स्थिति बहाल करें](cleanup.md) · [Privacy Guard की बूट रिपोर्ट पढ़ें](guard.md) · [जाँच के परिणाम](validation.md)

“About This TV” में मॉडल और फ़र्मवेयर मिलाएँ। परीक्षण में UE55BU8000UCCE (22_KANTSU2E_UB2), T-KSU2EBDEUC-1720.7, Tizen 6.5 और .NET Core 3.1 थे। कंप्यूटर पर Windows PowerShell, Python 3.12 या नया संस्करण, Git, Node.js, .NET SDK और Samsung SDB 4.2.36 इस्तेमाल हुए।

Apps में `12345` दर्ज करें, Developer Mode चालू करें और Host PC IP में कंप्यूटर का LAN पता भरें। पुष्टि करके टीवी की बिजली हटाएँ और दोबारा चालू करें। परीक्षण में प्लग 15 सेकंड निकाला गया था। अपडेट और फ़ाइल लेखन पूरा होने तक प्रतीक्षा करें। नीचे पते और SDB का पथ अपने अनुसार बदलें।

```powershell
$tvIp = 'TV_LAN_IP'
$pcIp = 'PC_LAN_IP'
$sdbPath = 'PATH_TO_SDB_EXE'
& $sdbPath connect "${tvIp}:26101"
& $sdbPath devices
```

देखें कि उपकरण सूची में टीवी दिखाई दे रहा है। VPN प्रयोग करते समय स्थानीय नेटवर्क का पता चुनें। सिस्टम में बदलाव के लिए टीवी पर पहले से कॉन्फ़िगर किए गए व्यवस्थापक अधिकार चाहिए। ऐप पर हस्ताक्षर करने के लिए अपने Samsung लेखक और वितरक प्रमाणपत्र इस्तेमाल करें जो इस टीवी के लिए मान्य हों। परीक्षण में Apps2Samsung CLI 3.0.0 और Partner प्रमाणपत्र इस्तेमाल हुए। प्रमाणपत्र और निदान लॉग निजी रखें।
