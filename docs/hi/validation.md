10 नवंबर 2026 को कंप्यूटर पर तीन Python परीक्षण सफल हुए। पैच लगाने और वापस लेने दोनों में अनजान बाइनरी फ़ाइलें अस्वीकार हुईं। बंद करने की सूची में सुरक्षित ऐप और ID में शेल के विशेष चिह्न भी अस्वीकार हुए। पैच लगाने और फिर उलटने पर DLL मूल फ़ाइल से बाइट-दर-बाइट मिली।

Windows ट्रांसपोर्ट पैच निर्धारित स्रोत संस्करण से मिला। दोनों .NET घटक बिल्ड हुए और बिना हस्ताक्षर वाला पैकेज ZIP तथा XML जाँचों में सफल हुआ। .NET Core 3.1 का समर्थन समाप्त होने की चेतावनी टीवी पर इस्तेमाल होने वाले रनटाइम से संबंधित है।

CI में Python परीक्षण, स्क्रिप्ट निर्माण, शेल और JavaScript सिंटैक्स जाँच तथा प्रकाशित फ़ाइलों की जाँच होती है। स्थानीय लिंक और निजी डेटा के लिए प्रकाशन की सामग्री भी जाँची गई। नीचे टीवी का रिकॉर्ड पहले किए गए कोल्ड बूट परीक्षण का है। सार्वजनिक टूल कंप्यूटर पर जाँचे गए।
