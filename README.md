# Очистка Tizen OS на Samsung BU8000 от лишних приложений и трекеров просмотра

Уберите «Рекомендации экспертов» из Smart Hub и оставьте во вкладке «Приложения» только то, что установлено на вашем Samsung Smart TV. Чтобы отключить встроенную аналитику Samsung и автоматическое распознавание контента (ACR), используйте отдельный профиль очистки. Оба изменения проверили на **UE55BU8000UCCE** с прошивкой **T-KSU2EBDEUC-1720.7** (Tizen 6.5). Ниже — инструкции с проверкой результата и откатом.

## Убрать «Рекомендации экспертов» из штатного меню

1. Сверьте модель и прошивку в меню «Об этом телевизоре». Сохраните оригиналы `AppsCommon.dll` и `AppsCommon.ni.dll` и сравните SHA-256 обоих файлов с таблицей. Для изменения нужны права администратора на ТВ. [Хеши и инструкция](docs/smart-hub.md)
2. При совпадении обоих хешей примените патч для вкладки **Home → Приложения**. Дождитесь конца просмотра, поскольку при применении перезапускается Home.
3. Снова откройте вкладку, запустите приложение и проверьте команду из умного дома. На тестовом ТВ подборки исчезли, приложения и управление работали. Для отката восстановите **обе** исходные библиотеки.

## Отключить встроенные приложения Samsung

1. Откройте профиль и посмотрите, какими функциями придётся пожертвовать. Среди 37 отключаемых компонентов есть голосовое управление, TV Plus, Gaming Hub и удалённая поддержка. Если используете их, пропустите полный профиль. [Списки отключаемых и сохраняемых приложений](profiles/bu8000-1720.7.json)
2. На ПК выполните `python tools/generate_cleanup.py`. В папке `build/cleanup/` появятся скрипты применения, проверки и отката. Для применения на ТВ нужны права администратора. Сохраните `baseline.tsv`, созданный при первом применении: в нём исходное состояние каждого приложения. [Применение и откат](docs/cleanup.md)
3. Запустите `verify.sh`, откройте установленное приложение и отправьте телевизору команду из умного дома. Для отката выполните `restore.sh` с сохранённым исходным состоянием и перезапустите ТВ.

В записи одного холодного запуска у всех семи выбранных служб, включая распознавание контента, были `inactive` и `MainPID=0` на 85-й секунде. Проверка проводилась с `Host PC IP = 127.0.0.1`. Публичные инструменты проверены на ПК. [Запись проверки на ТВ](evidence/cold-boot-sanitized.json) · [Проверки публичной версии](docs/validation.md)
