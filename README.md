# Samsung BU8000 Lab

Практические заметки и исходники для **Samsung UE55BU8000UCCE**, Tizen **6.5**, прошивка **T-KSU2EBDEUC-1720.7**.

Проект вырос из эксперимента на одном домашнем телевизоре 27–28 октября 2026 года. Цель — отключить выбранные службы распознавания контента и аналитики, убрать подборки в штатной вкладке «Приложения» и сохранить умный дом, YouTube и Media Station X. Публикация подготовлена 10 ноября 2026 года; состояние телевизора в этот день заново не проверялось.

**Это исследовательский набор для конкретной прошивки, а не универсальный debloater Samsung.** Подключение SDB, права владельца и root — разные уровни доступа. Новая публичная упаковка проверяется локально; её повторная установка на ТВ не выполнялась.

## Что получилось

| Изменение | Результат на исследованном ТВ | Ограничение |
|---|---|---|
| Отключение 37 компонентов | Выставлены app-флаги отключения | Это не удаление файлов прошивки |
| Остановка 7 служб, включая contents-recognition и canalysis | После холодного запуска: masked, inactive, MainPID=0 для всех семи | Проверено с Host PC IP = 127.0.0.1; с адресом ПК автономность не доказана |
| Подборки экспертов в штатной вкладке Apps | Исчезли; пользователь подтвердил работу приложений и умного дома | Патч привязан к точному SHA-256 DLL; обновление может его заменить |
| SmartThings / умный дом | Пользователь подтвердил управление после очистки и удаления подборок | Не проверены все функции Samsung |
| Отдельный ярлык Zona | Работали каталог, пульт, видео и звук; пользователь не заметил лагов | Позже отвергнут из-за малого выбора озвучек |
| Vetro | Новый Home работал в одном сеансе | Холодный старт не устроил; удалён, штатное меню возвращено |
| Q-Symphony с HW-B650 | Принудительно появился пункт меню | Совместный звук не заработал; HDMI остался проблемным |
| Замеры RAM/CPU | Полноценного сравнения нет | Измерения отменены; проценты ускорения не заявляем |

Техническое свидетельство: [обезличенный результат холодного запуска](evidence/cold-boot-sanitized.json). Это историческое наблюдение, не гарантия отсутствия всех сетевых обращений или повторного старта служб позднее в сеансе.

## С чего начать

1. Сопоставьте полный код модели, прошивку и хеши: [подготовка и доступ](docs/setup.md).
2. Изучите [отключения, последствия и откат](docs/cleanup.md). Голосовое управление, TV Plus, Gaming Hub и удалённая поддержка входят в полный экспериментальный профиль.
3. Для подборок Apps прочитайте [инструкцию патча](docs/smart-hub.md). Остановка рекламных служб сама по себе их не убрала.
4. Разберитесь с [Privacy Guard](docs/guard.md), прежде чем менять Host PC IP.
5. [Медиа-приложения](docs/media.md) и [неудачи экспериментов](docs/lessons.md) описаны отдельно.

## Состав

- `profiles/` — списки приложений, служб и хеши патча.
- `tools/generate_cleanup.py` — генерация shell-скриптов с baseline и откатом; без подключения к ТВ.
- `tools/patch_apps_common.py` — локальный патчер, отказ на неизвестном хеше, обратное преобразование.
- `guard/` — исходники однократного помощника загрузки; отчёт остаётся на ТВ.
- `tools/build_msx_shortcut.py` — отдельные ярлыки без изменения существующего MSX.
- `evidence/` — выбранные обезличенные результаты.
- `tests/` и CI — проверки отказа на неподходящих данных и синтаксиса.

Закрытых DLL Samsung, подписанных пакетов, сертификатов, токенов, аккаунтов, дампов устройства и SDB-бинарников здесь нет. Собственные резервные копии храните вне Git, например в игнорируемом `private/`.

## Проверки без телевизора

```powershell
python -m unittest discover -s tests -v
python tools/generate_cleanup.py
python tools/check_public_tree.py
python tools/build_guard.py
```

Последняя команда требует .NET SDK и пакеты целевой платформы .NET Core 3.1. Предупреждение об устаревшем target ожидаемо: он выбран под runtime этого ТВ. Создаётся **неподписанный** WGT; установка не выполняется.
